## Общие рекомендации для всех промптов:

### Для лучших результатов добавьте:
- `--ar 4:3` (для property фото) или `--ar 1:1` (для портрета) если используете Midjourney
- `--style raw` для более реалистичного вида
- `--quality 2` для максимального качества
- `photorealistic, professional photography, 8K, ultra detailed, sharp focus`

### Ключевые слова для профессионального вида:
- **Lighting**: golden hour, soft natural light, professional studio lighting, HDR
- **Quality**: photorealistic, 8K, ultra detailed, sharp focus, DSLR quality
- **Style**: architectural photography, professional real estate photography, editorial
- **Mood**: professional, luxury, modern, clean, sophisticated, trustworthy

### Для DALL-E 3:
Промпты можно использовать как есть, DALL-E 3 хорошо понимает детальные описания.

### Для Midjourney:
Добавьте в конце:
```
--ar 4:3 --style raw --quality 2 --s 250
```

### Для Stable Diffusion:
Используйте модели:
- **Портрет**: Realistic Vision v5.1 или DreamShaper
- **Архитектура**: ArchitectureExterior или ModernInterior

### Negative prompts (что исключить):
```
cartoon, anime, sketch, drawing, painting, unrealistic, distorted, blurry,
low quality, pixelated, oversaturated, ugly, deformed, bad architecture,
cluttered, messy, people (for property photos), cars blocking view,
bad lighting, overexposed, underexposed, noise, grain, artifacts
```

## После генерации изображений:

1. **Оптимизируйте размер:**
   ```bash
   # Установите imagemagick
   brew install imagemagick  # macOS

   # Измените размер и оптимизируйте
   convert input.jpg -resize 800x800 -quality 85 adrian-varga-portrait.jpg
   convert input.jpg -resize 1200x900 -quality 85 property-1.jpg
   ```

2. **Или используйте онлайн:**
   - https://squoosh.app/ (Google)
   - https://tinypng.com/
   - https://compressor.io/

3. **Целевой размер файлов:**
   - Портрет: 100-200 KB
   - Property фото: 200-400 KB каждое

## AI Генераторы (рекомендации):

### Лучшее качество:
1. **Midjourney v6** - лучший для архитектурной фотографии
2. **DALL-E 3** - отличная реалистичность, хорош для портретов
3. **Stable Diffusion XL** - бесплатный, настраиваемый

### Бесплатные опции:
1. **Bing Image Creator** (DALL-E 3) - бесплатно
